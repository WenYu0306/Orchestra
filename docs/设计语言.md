# Orchestra 设计语言 v1

> 2026-11-15 与用户共同确认。所有 UI 改动以本文档为唯一标准；争议回此裁决。
> 布局参照：BOSS 直聘 web 版（品类霸主，数亿用户样本打磨的主从式）。

## 一、定位

**求职决策台**——不是后台管理系统，不是营销页。买家每天打开它做的事：审阅队列 → 深读一个 → 改招呼语 → 决定发送。界面为此服务。

## 二、布局：主从式

- **左列表（约 360px）**：紧凑岗位行（分数 + 公司 + 薪资），扫读用；点击任一行 → 右侧切换详情（默认选第一行）
- **右详情（自适应）**：选中岗位的完整决策面——公司/职位/薪资、匹配理由全文、招呼语编辑器、复制/发送
- **顶部叙事带**：一句话 + 大数字（"今天为你找到 7 个岗位，5 个值得投"）
- **底部发送栏**：sticky，批量发送入口 + 计数
- **低于投递线**：Tab 切换，左列表显示紧凑行情行（无详情面板）

## 三、色彩

| 名 | 值 | 用途 |
|---|---|---|
| 纸 | `#faf7f0` | 页面底色（cuelume 暖调锚点） |
| 卡 | `#ffffff` | 列表行/详情面板 |
| 墨 | `#1a1a1a` | 主按钮、品牌 mark、大分数、选中边 |
| 墨绿 | `#0d7a5f` | **唯一信号色**：值得投（≥80 左缘边）、已发送、选中框 |
| 灰 | `#94a3b8` / EP 灰阶 | 次要文字 |
| 红 | `#ef4444` | 仅失败态 |

禁用：琥珀/赤陶橙（Claude 标志脸）、靛紫渐变、毛玻璃、彩色胶囊标签。

## 四、排版

**字号五档（全站只允许这五档）**：56（详情分数）/ 22（叙事页题）/ 18（节题与向导题）/ 14（正文默认）/ 12（辅助说明）。分数左列紧凑行 20 为附档。

- 一个家族走天下：系统 sans（PingFang/微软雅黑栈）
- **分数是视觉主角**：56px / 800 字重 / tabular-nums / 墨色——不靠颜色靠体量
- 叙事带标题 22px/800；正文 14px/400；辅助文字 12px
- 禁：13/11.5/12.5 这类"差不多"尺寸、标题内单词高亮、全大写标签、中点连接串、装饰性编号

## 五、组件

- 交互件一律 **Element Plus**（按钮/输入框/抽屉/对话框/消息），禁止手搓仿制
- **按钮两档**：large（40px，主流程：开始/停止/发送选中/向导导航）、default（32px，次级）；复制类内联小按钮可用 small。禁用三种档位混排
- **声音一律 cuelume**：tap（主按钮）、success/error（发送结果）、ready（评分完成）、loading（运行开始）
- 层级/状态标记：左边框 + 文字（不用彩色胶囊）

## 六、动效

- 仅状态反馈（选中边、hover、加载态），无入场动画、无滚动戏剧化

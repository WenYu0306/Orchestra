# Orchestra 使用手册

AI 求职助手：自动搜索 → 简历匹配打分 → 分层展示 → 生成个性化招呼语 → 你确认后按真人节奏发送。

## 快速开始

> 前提：电脑已安装 **Google Chrome**（本工具通过 Chrome 自动化操作，Edge 等其他浏览器不支持）。

1. **解压** Orchestra 压缩包到任意文件夹
2. **双击启动**：macOS 双击 `启动.command`；Windows 双击 `启动.bat`
3. 首次启动会出现**五步引导**：阅读说明并确认 → 上传 PDF 简历 → 填入 DeepSeek API Key（有申请教程和即时校验）→ 选择城市和期望薪资 → 扫码登录 BOSS 直聘
4. 引导完成后点「开始」，AI 自动搜索打分；完成后逐条查看卡片，**勾选想要的岗位 → 「发送选中」**

> macOS 首次运行若提示"无法验证开发者"：右键 `启动.command` → 打开 → 再点「打开」；
> 或在终端执行 `xattr -d com.apple.quarantine ~/下载路径/Orchestra/Orchestra`。
> Windows 若弹出 SmartScreen 蓝色警告：点「更多信息」→「仍要运行」。

## DeepSeek API Key

- 申请：https://platform.deepseek.com 注册后在「API Keys」页创建
- 充值 10 元即可长期使用（一次完整运行通常花费几毛钱）
- Key 只保存在你电脑的 `.env` 文件里，不会上传给任何人
- 填入时点「验证」可即时校验并查看余额

## 日常使用

1. 双击启动，进入主界面（原生窗口，不是浏览器网页）
2. 点「开始」→ 若 BOSS 登录态过期会自动弹出 Chrome 扫码窗口（平时免扫码）
3. 等待评分完成（界面实时显示进度，每条岗位有匹配分和理由）
4. 结果分两个页签：**可投递**（≥ 60 分，已生成可编辑的招呼语）和**低于投递线**（< 60 分，默认折叠，可展开自查）
5. 招呼语可以直接编辑再发；勾选想要的岗位 → 「发送选中」，系统按 45~120 秒/条的真人节奏逐条发送
6. 每日上限默认 25 条（config.yaml 里 `safety.daily_send_cap` 可调）
7. 关闭窗口即完全退出，不会留后台进程

## 常见问题

| 问题 | 处理 |
|---|---|
| 双击后窗口没出现 | 等约 10 秒；若弹出「启动失败」提示窗，多为端口被占用——关掉已在运行的另一个 Orchestra 再试，或编辑 config.yaml 改 `web_ui.port` |
| 提示「未找到 Google Chrome」 | 先安装 Chrome（google.cn/chrome）再重新启动 |
| 提示「DeepSeek Key 无效」 | 点提示横幅直达设置，重新完整复制 Key（sk- 开头） |
| 提示「DeepSeek 余额不足」 | 到 platform.deepseek.com 充值后重试 |
| 提示「登录态已失效」 | 重新点「开始」，在弹出的 Chrome 窗口扫码即可 |
| 提示验证码/风控 | 系统会自动停止保护账号；在 Chrome 窗口手动完成验证后重新点「开始」 |
| 搜不到岗位 | 检查设置里的城市；确认简历已上传 |
| 招呼语显示「默认文案」 | DeepSeek 偶发生成失败会降级为通用语，建议手动改写后再发送 |
| 想换城市/期望薪资 | 设置里改完保存，下次点「开始」即生效（搜索关键词由 AI 按你的简历自动生成，无需填写） |
| 我所在的城市不在列表里 | 目前支持 73 个主要城市（覆盖全部一线及主要二线就业市场），其余城市持续增加中，欢迎反馈 |

## 重要声明（请务必阅读）

1. 本工具为**个人求职效率工具**，通过浏览器自动化操作你本人登录的 BOSS 直聘账号。平台用户协议通常限制自动化操作，存在账号被限流/限制的可能。请知悉并自担风险，控制使用频率。
2. 工具默认按真人节奏运行（发送间隔 45~120 秒、每日上限 25 条、连续失败自动熔断）。**请勿调低这些参数，勿用于批量营销**。
3. 你的简历文本会通过你自己的 DeepSeek API 用于匹配评分和招呼语生成。
4. 本工具不收集、不上传任何数据到开发者服务器；所有数据（投递记录、日志、浏览器登录态）都保存在本机 `data/` 目录，删除该目录即清除全部痕迹。
